# MediNest Pharmacy (demo)

Mobile-first demo website for a local pharmacy: photo slideshow hero, product search, cart with WhatsApp ordering, and prescription upload.

- `index.html` is the built site (served by GitHub Pages).
- Edit `src/page.html`, then run `node build.mjs` to rebuild `index.html`.
- Shop name, phone, WhatsApp number and address are placeholders in `src/page.html` (`SHOP` object and store section).
